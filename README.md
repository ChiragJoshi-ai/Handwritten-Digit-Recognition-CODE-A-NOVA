## 📌 Repository Overview

<p style="line-height: 1.6;">
This repository contains multiple <b>Basic AI Projects</b> developed as part of an 
<b>internship at Code-A-Nova</b>.

All projects in this repository were developed as part of an **internship assignment at Code-A-Nova**.

### 💬 Sentiment Analysis
<p>
